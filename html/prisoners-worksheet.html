The 100 Prisoners Problem

Understanding the Problem

The Setup. 100 prisoners are each assigned a unique number from 0 to 99. In a room there are 100 boxes, also numbered 0–99. Each box contains a slip of paper with one of the 100 numbers — placed randomly, one per box.

One by one, each prisoner enters the room alone and may open at most 50 boxes. If they find the slip with their own number — they succeed. They must then leave the room exactly as they found it. Prisoners cannot communicate after the game begins.

Win condition: ALL 100 prisoners must find their number. If even one fails, everyone is executed.

The Chain Strategy. Each prisoner starts at the box with their own number, reads the value inside, and goes to that box next — following the chain until they find their own number or exhaust their 50 attempts.

Key insight: The arrangement of slips defines a mathematical permutation. A permutation decomposes into disjoint cycles. The chain strategy succeeds if and only if no cycle is longer than 50.

Why does it work? All prisoners follow chains rooted in the same permutation. Their fates are statistically correlated — they either all find short cycles, or they all suffer a long one. The probability that no cycle exceeds 50 is 1 − ln(2) ≈ 31.18%.

PROVIDED generateUniqueRandomArray(int n) ▼

This function is given to you. It returns an array of n unique integers from 0 to n−1, shuffled randomly using the Fisher-Yates algorithm. You don't need to modify it — just call it.

/**
 * Returns an array of n unique random integers in [0, n-1].
 * Uses Fisher-Yates shuffle — O(n), uniform distribution.
 */
static int[] generateUniqueRandomArray(int n) {
    if (n < 0)
        throw new IllegalArgumentException("n must be non-negative");

    int[] arr = new int[n];
    for (int i = 0; i < n; i++) arr[i] = i;

    Random rand = new Random();
    for (int i = n - 1; i > 0; i--) {
        int j = rand.nextInt(i + 1);
        int tmp = arr[i]; arr[i] = arr[j]; arr[j] = tmp;
    }
    return arr;
}
